KAMERIN'S FAIRY FIRST WEBSITE INVITATION

Open index.html in a browser to preview the invitation.

To publish it online:
1. Upload the entire folder to Netlify Drop, GitHub Pages, Vercel, or your web host.
2. Keep the index.html, styles.css, script.js, and assets folder together.
3. Optional music: place an MP3 named fairy-music.mp3 inside the assets folder.

Included features:
- Animated welcome page for “You are invited!”
- Fairy-door entrance button
- All seven invitation designs preserved as the website content
- Animated page reveals and navigation dots
- Live countdown to September 19, 2026 at 10:00 AM (Philippine time)
- Church and reception map buttons
- Click-to-open RSVP form modal
- Add-to-calendar button
- Share invitation button

Important note about the RSVP form:
- The current RSVP form is interactive and saves the latest response on the visitor's device.
- If you want the RSVP form to actually send responses to your email, Google Sheet, or Google Form, the site can be connected in a later update.

Note: The invitation images are optimized into WebP and JPEG versions for faster loading.
